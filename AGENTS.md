# BigBattle working agreement

- Target Tuanjie 1.9.3 / editor 2022.3.62t11, Windows x64. This is a native Unity project, not a browser game.
- Read README.md, Docs/DESIGN.md, and update.md before changing the project.
- Every completed update must append a dated entry to update.md: changes, validation, known limits, and next steps. Commit and sync to https://github.com/xiaoyue12306/BigBattle after validation. Do not claim sync without checking the remote commit.
- MVP scope: one keyboard OR Xbox controller controls one banana assassin; facing-based attacks without a mouse; training dummy and a short solo PvE arena battle.
- Future scope: up to FIVE local players (three Xbox controllers and two keyboard players), automatic split screen, cooperative and versus modes. Do not present future features as implemented.
- Keep device input, actors, combat, session rules, and cameras separate. Two keyboard layouts may share the Windows keyboard stream; distinguishing two physical keyboards requires a future Windows Raw Input backend.
- No equipment, progression, matchmaking or networking unless requested. v0.6.0 Flower Lane adds mode-specific minions, towers and cores under the user's new single-lane battle request; keep those out of garden practice / three-wave challenge.
- Preserve .meta files. Ignore Library, Temp, Logs, Artifacts, and Builds. Do not commit system fonts, third-party art without a license, or generated executable binaries.
- Use Tools > BigBattle to rebuild the scene and Windows player. Run the standalone smoke test after gameplay changes. Record physical controller testing separately from automated input tests.
- v0.2.0 uses a LOCAL Mixamo library; read Docs/MIXAMO.md. Never commit the raw FBX or baked motion data to the public repository. Prepare the user's Sword and Shield Pack with Tools/PrepareMixamo.ps1; the build bakes 13 proportion-adapted tracks. Without them only procedural fallback is available, and full animation acceptance must fail rather than silently claiming Mixamo support.
- Hit pause is coordinated by GameRoot: preserve pause precedence and reset/recovery. Synchronize contact events with motion timing. Do not make new effects bypass mute or allocate permanent per-hit materials/meshes.
- v0.4.0 banana effects use shared procedural meshes and BigBattle/BladeEnergy, retained explicitly by ProjectBuilder. Read Docs/BANANA_VFX.md before replacing them; keep finite mesh endpoints, paused vortex behaviour, effect limits and cleanup. Store VFX candidates have not been downloaded or integrated.
- v0.5.0 adds selectable Yueyue; read Docs/YUEYUE.md. Preserve user-supplied derived Resources/Yueyue FBX / texture and their .meta; original FBX / Blender intermediates stay local. Keep Ultimate edge and UltimateHeld separate for Xbox/keyboard, hard binds distinct from ordinary hit stun, real-death owner attribution, half-stat summons and once-per-target swept doom hits. H / D-pad left is practice-only; never grant dummy kills or skip the 20s release cooldown in battle. Revalidate both heroes, charge interruption / reset, and summons on changes.
- v0.6.0 Flower Lane is ONE human plus nine AI, not local multiplayer. Read Docs/FLOWER_LANE.md. Keep preferred and active mode separate, route all movement / summon / peel clamps through GameRoot.Clamp, preserve per-hero cooldowns and souls on lane respawn, protect objective order and backdoor reduction, and clear lane actors / timers on exit. Run both regular acceptance and the accelerated LaneSimulation; report real rendering / input / timing limitations separately.
- v0.7.0 rotates Flower Lane 45 degrees in world space. Use FlowerLaneMap.ToWorld / ToLane / Forward / Across for all lane positions and offsets; keep the camera yaw fixed so the route projects lower-left to upper-right. Yueyue now uses 13 actually acquired Kenney CC0 textures and the built-in particle module; read Docs/SOUL_VFX.md and AssetLibrary/VFX/Kenney-ParticlePack/SOURCE.md. Preserve licenses / original texture hashes, shared materials, paused particle clocks, reusable charge / phase cleanup and frozen afterimages without live emitters. This does not mean prior Asset Store candidates were acquired.
- v0.8.0 refines the same 13-bone Yueyue skin for the actual bent left arm. Read Docs/YUEYUE_MOTION.md. YueyueVisual owns the caster body (ActorVisual.ExternalBodyPose), distance-based gait, three cosmetic basic gestures and hand-following sword IK; never scale limbs or move the combat actor from presentation. Preserve original texture/meta and refined FBX. Seven CC0 atlases / 212 frames from Kutejnikov, Cethiel and para are actually integrated; retain source hashes/licenses, atlas import sizes/padding and paused interpolation. GameRoot explicitly pauses active SoulVfx native emitters; resume only previously paused emitters. CaptureCloseup is diagnostic-only. Revalidate motion/pause/reset, both heroes, all soul/charge rules and full lane matches.
