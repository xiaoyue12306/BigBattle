## 使用

启动时用 W/S、方向键或 Xbox 左摇杆切换英雄，Enter / A 确认。暂停菜单可重新选择英雄，并切换 G / 十字键右召出的陪练类型。换角色、重开、练习 / 挑战切换均清空战斗状态。

| 操作 | 键盘 / Xbox | 规则 |
| --- | --- | --- |
| 移动与朝向 | WASD / 左摇杆 | 生命 155，移动速度 4.8；停止移动保留朝向。 |
| 追魂骷髅 | J / X，可按住 | 每 0.65 秒一颗、伤害 28。身侧悬停 0.35 秒后加速，速度最高 18；发射时在前方锥内寻找最近目标，有限转向追踪。无目标沿朝向飞出，命中首个敌人消失。 |
| 幽冥铁索 | K / A | 直线铁索，伤害 12；命中首个敌人后出现虚空锁链，禁移动、攻击及施法 2 秒，目标仍可受伤。出手即开始 10 秒冷却，落空也计冷却。 |
| 亡者归来 | L / B | 召出最近被本人或所属亡魂击败的真实敌人；保留外形和基础攻击类型，最大生命及攻击各减半。最多一名，存在 20 秒，冷却 25 秒。自主索敌战斗，无敌人时跟随主人。 |
| 虚无鬼影 | 空格 / LB | 持续 3 秒，解除已有控制，拒绝伤害和控制；保留移动，但禁止攻击、施法及召唤。出手即开始 8 秒冷却；可穿过角色，受场地边界约束。 |
| 万魂魔剑 | 按住再松开 I / Y | 三枚魂印才可开始；四秒蓄力，移速只剩 10%，可调整朝向，其他动作被锁定。蓄满后可继续持剑等待，松开斩出。消耗三魂印，释放时开始 20 秒冷却。 |
| 练习充能 | H / 十字键左 | 仅练习模式：补足三魂印并清除大招冷却，便于反复查看效果。挑战中无效。 |

本人或所属亡魂完成真实敌人的击杀才获得魂印；木桩、无限复原的陪练和召唤物不提供魂印。多余魂印保留（上限 99），释放只扣三枚。没有击败记录时 L 不可用。召唤物复制基础攻击，不递归复制召唤 / 大招等技能；团子为近战、香蕉为武器斩击、越越大王为追踪骷髅。

普通受伤不会取消蓄力；铁索等硬控制、死亡会取消。提前松开同样取消。这些取消不扣魂印、不开大招冷却，需要松开键后才能重新开始。暂停停止蓄力和技能生命周期，恢复后继续按住可保持蓄力。

大招剑气方向在释放时固定，不追踪；贯穿沿途敌人，每个目标最多受到一次 500 点伤害。速度 24、生命周期 3 秒，空旷路径约 72 单位，超过当前场地直径；地面裂痕为视觉表现，每段 4.6 秒内渐隐回收。8.8 单位高的黑色立体竖刃叠加青绿、蓝、红刃缘，配合三色魂流、剑身抖动、蓄满提示、释放闪光、整幅游戏视口的镜头震动、短暂拉远及手柄震动请求。真实手柄 / 电视体验尚未实测。

## 角色素材与动作

- 用户提供静态 FBX：`C:\Users\xy\Pictures\bb\yueyue.fbx`，33,963,996 字节，单个网格 24,932 顶点，内嵌四张 4096² 贴图，没有骨骼和动作。
- 保留原始文件，Blender 5.2.2 脚本另行生成 2.25 单位高的角色、13 骨骼和柔性分区权重；提取并缩小主色贴图至 2048²，生成 Resources/Yueyue/Yueyue.fbx（1,924,044 字节）和 YueyueColor.png（5,124,441 字节）。来源校验见 Validation/yueyue-assets.json。
- 这是用户提供的外形及其项目适配结果；不将它标记成 CC0 或从商店下载的模型。源码同步只加入游戏用衍生 FBX / 贴图；原始 FBX、Blender 中间文件留在原位置及本地 Artifacts。
- 使用本次自制的行走摆腿、抬手施法、举剑蓄力、挥剑及倒下姿势；没有声称从 Mixamo 下载新动作，也没有把香蕉比例的 Mixamo 姿态直接套到这个人形模型。
- 骨骼是依据该静态姿势制作的基础游戏骨架与权重，肩部、交叠手臂和头巾不是专业人工逐顶点精修蒙皮。未来可以替换为专业绑定 / 动作，保持运行时骨骼名与动作接口即可。

本机重建素材：先运行 Blender `--background --python Tools/InspectYueyue.py`，再运行 `--background --python Tools/PrepareYueyue.py`，最后运行 `--background --python Tools/RefineYueyueRig.py` 应用 v0.8.0 非对称手臂修正。脚本默认读取上述用户原文件；导出到工程 Resources，`.blend` 与检查渲染只写入 Artifacts。普通构建不需要 Blender，直接使用已生成的 FBX；v0.8.0 输出 1,972,060 字节，原贴图保持原校验值。

## 代码与扩展

- `Combat/YueyuePlayer.cs`：独立技能、魂印与最近击败快照；复用现有玩家控制器的虚接口以保持原香蕉调用兼容。
- `GhostProjectile.cs`：骷髅悬停 / 加速 / 转向、铁索首个接触和大招扫掠碰撞。每帧按移动线段检测，穿透剑气保存已命中集合，避免高速穿过和重复伤害。场内投射物上限 48。
- `SpiritAlly.cs`：所属玩家、20 秒生命周期、半属性和三种基础攻击 AI；`YueyueDuelist` 为可选陪练及可击败的敌方英雄。
- `Combatant.Bind / Cleanse`：硬控制与虚无免疫；控制立即取消待结算武器攻击，并打断魔剑蓄力。敌方 AI 也会选择攻击召唤物。
- `GameRoot.RecordDefeat`：在真实死亡前保存外形 / 最大生命 / 基础攻击，统一处理本人及召唤物的击杀归属。归来亡魂死亡不加敌人击败分数。
- `Visuals/YueyueVisual.cs`：加载用户模型、骨骼姿势、透明鬼影、黑绿魔剑、固定数量魂流与光环。`GhostArt` 提供共享材质、骷髅形状、铁链 / 禁锢及亡魂光效。
- 选择越越大王挑战时，第二波最后一名为可击败香蕉，第三波最后一名为可击败越越大王；总敌人数仍为九，方便在实际战斗中获得英雄亡魂。香蕉原有三波团子挑战保留。

运行 `Tools/Build.ps1`、`Tools/Smoke.ps1`、`Tools/CheckSource.ps1` 验证。`Tools/PreviewYueyue.ps1` 录制真实运行画面，`Tools/MakeYueyueGif.py` 依时间戳生成预览，接受检查的固定场景不代表人工完成了 USB 手柄游玩。
