# 海克斯大乱斗 · 冰雪嚎哭深渊方向

v0.13.0，2026-10-21。按用户选择 **A：冰雪嚎哭深渊**，替换原花溪大乱斗。保留左下至右上的单路、现有角色和无需鼠标的操作，地形改为悬空冰桥、深蓝峡谷、积雪城垛、火盆、石像与蓝 / 红水晶建筑。

这是一套本项目的原创程序几何和适配规则，并非导入英雄联盟地图或逐像素复刻。目标是接近该地图的地形结构、建筑轮廓与冷暖配色；角色仍沿用本项目的卡通外观。花园练习、英雄陪练、三波挑战继续使用原地图。

## 开始与操作

练习中按 **N / Xbox 十字键上**，或在暂停菜单选择海克斯大乱斗。先随机抽取香蕉刺客、越越大王、阿狸之一，可 **R / Xbox Y** 重随机两次，每次保证换人；女巫技能未设计，不参与随机池。确认 **Enter / Xbox A** 后进入冰桥并选择首项强化。阵容为一名真人加四名 AI 对抗五名 AI，双方可重复角色。没有多人加入、分屏或网络。

强化从三个选项中选一个：**W/S、方向键 / 左摇杆、十字键**切换，**Enter / A** 确认；**R / Y** 每轮刷新一次，三张刷新牌不重复旧选项。选择期间整个战斗暂停，**Esc / Menu** 取消整局回练习。战斗操作仍用 J/K/L/Space/I 对应原技能；阿狸只有 J/X 爆泡。

在己方出生点左侧传送门附近按 **E / 十字键右**，引导一秒后传到己方外塔前；外塔被毁后传到内塔前。移动、受伤、硬控制、死亡取消引导，每个角色八秒冷却。AI 也实际走到传送门并使用同样规则。模式内十字键右不再开陪练。F / View 返回练习。

## 地图与对局规则

- 桥面局部纵轴 -44～44，中央宽 12，基地向两侧扩至 18；世界坐标旋转 45°，正常固定相机朝向下呈左下 → 右上。`FlowerLaneMap.ToWorld / ToLane / Forward / Across` 仍是统一坐标接口。走路、击退、位移、召唤通过 `GameRoot.Clamp`，额外绕开存活建筑占地；AI 有局部绕行。没有高低层、跳崖或完整 NavMesh。
- 双方各有**外塔 → 内塔 → 召唤水晶 → 两座基地塔 → 基地核心**。外 / 内 / 基地塔各 900 HP，水晶 600，核心 1800；前序目标未毁时后序免伤。两座基地塔均摧毁才开放核心。核心摧毁立即结算，停止余下攻击 / 出兵 / 爆泡判定。
- 水晶被毁 **300 个游戏秒**后复生，并重新保护后方尚存建筑。按用户要求**不生成超级兵**。
- 首波 **15 秒**，之后 **25 秒**一波，每队三近战、三远程；每第三波多一炮车，每方最多 30 名存活小兵。近战初始 55 HP，远程 38，炮车 105；初始攻击 7 / 7 / 12。新出兵随对局时间逐渐增强，15 分钟达到并封顶生命 +80%、攻击 +50%，不关联英雄经验等级。小兵沿桥推进、攻击敌人和开放建筑，远程 / 炮车有可见弹道。
- 建筑附近八单位内没有进攻方小兵时，受到伤害降低 80%。塔优先攻击小兵；附近敌方英雄攻击己方英雄会引起塔仇恨，持续 2.5 秒。塔范围 7，每 1.05 秒发射，连续攻击同一英雄逐步增伤。建筑免疫控制 / 击退，不提供英雄亡魂外形记录。
- 英雄死亡初始 **8 秒**复活，此后每完整对局分钟增加两秒，最多 32 秒，让中后期击败能够转化为推进窗口；死亡时记录本次等待长度。原有技能冷却继续计时，魂印、击败记录、本局强化和已放泡泡保留；取消未完成攻击、蓄力和控制。原出生保护 1.5 秒。没有回城、泉水自动治疗；敌方泉水造成高额防守伤害。
- 四处治疗圣物首次 40 秒出现，拾取后 40 秒刷新。受伤英雄靠近自动拾取，先治疗 10 + 已损生命的 8%，2.5 秒预警后对三单位内双方英雄治疗 20 + 已损生命的 10%。不治疗小兵 / 建筑。
- 四片桥侧草丛参与共享视野：己方英雄 14、小兵 8、建筑 12 单位；草内敌人需己方进入同一草丛或敌人攻击显形才能锁定。不可见仍可被盲放范围技能命中。普通世界标签、小地图和 AI 索敌遵循视野，地面迷雾约 0.15 秒更新。建筑轮廓始终标记。

这些计时、生命与地图单位是本项目首版适配值，不宣称与某个英雄联盟补丁逐项相同。没有金币、经验等级、技能升级、商店装备或持续成长；没有额外设计召唤师技能。原角色的技能 / 硬控制 / 拼刀 / 伤害归属仍沿用各角色文档。

## 强化：18 项通用 + 每位英雄 4 项

原版按等级发放的强化在此改为**开局、3 / 6 / 9 分钟**，最多四项，不重复获得，离开本局清除。九名 AI 同轮自动从自己的三张有效牌中选一张；真人手选。白银 / 黄金 / 棱彩是展示分类，本项目首版可在同轮出现不同分类，不模拟原版完整稀有度分发。没有永久解锁。

## 代码与验证入口

- `Visuals/AbyssMap.cs`：原创静态地图、合批、建筑轮廓。`FlowerLaneMap.cs` 保留旋转坐标和边界兼容接口；序列化 `MatchMode.FlowerLane` 值保留为 1，界面统一改名。
- `Modes/LaneMatch.cs / LaneStructure.cs / LaneMinion.cs / LaneHeroBot.cs`：阵容、兵线、复活、目标链、真实英雄 AI。`MayhemRules.cs`：选择、传送、治疗、草丛 / 迷雾、建筑占地。
- `Modes/MayhemAugments.cs`：三十张牌及真实伤害 / 生命 / 控制 / 冷却挂钩。强化状态随比赛退出恢复，不通过 Timeline 调度伤害。触发伤害有递归保护，效果沿用有限池 / 共享材质。
- `UI/MayhemHud.cs`：真人随机及三选一模态 UI；`GameHud.cs`：建筑 / 核心状态、小地图。`Input/LocalInput.cs`：R / E 与 Xbox Y / 右方向键分模式分派。
- `Diagnostics/LaneChecks.cs / MayhemChecks.cs` 覆盖真实入口、建筑链、三十张牌挂钩、300 秒水晶及四轮选择。`Tools/Smoke.ps1` 运行独立玩家验收；`Tools/LaneSimulation.ps1` 运行三种固定主控、自动强化的完整 AI 比赛；固定角色是诊断入口，不替代真人随机 UI。
- `Tools/PreviewLane.ps1` 录制实际玩家帧；全图俯视仅为诊断相机，正常游戏仍跟随角色。报告与限制见 [VALIDATION.md](VALIDATION.md)。原模型 / .meta、CC0 素材与本地 Mixamo 约定保留。
