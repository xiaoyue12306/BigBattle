## 实现和维护

- `SoulVfx` 管理固定层数贴片、Shuriken 粒子、暂停时钟和可复用的蓄力 / 虚无状态。临时命中特效经 Feedback 根节点的 220 上限创建，弹体仍有 48 上限；每个发射器最多 64 粒子，聚能发射器最多 120。上限不是多人性能承诺。
- `Art.SoulMaterial` / `SoulQuad` 缓存共享材质和四边形，游戏退出交给 `Art.Cleanup` 销毁。颜色 / 流动参数使用 MaterialPropertyBlock；每次命中不新建永久材质 / 网格。
- `BigBattle/SoulParticle` 支持透明烟雾与 HDR 叠加发光，加入局部纹理流动和亮芯；三色聚能流使用闪电贴图沿弯曲路径展开，避免纯色线条像电线。自制 `SoulBloom` 在四分之一分辨率提取超过 1.35 的亮部并柔化合成，以较小强度表现魂焰光晕；普通明亮地形不会全屏泛白。相机开启 HDR，`ProjectBuilder` 显式保留两个 Shader；不依赖外部后处理包、GrabPass、URP / HDRP 或 VFX Graph。
- `SoulTextureImporter` 固定透明通道、Clamp、512 上限、双线性和无 Mipmap。关闭状态清空粒子，再次进入技能重新播放；一局重开销毁短效并关闭持有特效。普通角色受击闪白不覆盖粒子颜色。
- 蓄力可被硬控 / 死亡打断，练习重开 / 模式切换清理；魂流坐标随当前剑尖计算。召唤 / 束缚的视觉寿命不延长实际技能时间。

验证与实际截图见 [VALIDATION.md](VALIDATION.md)。真实 Xbox、电视、多视口粒子负载仍需要实测。此版改善粒子层次，不包含专业手工角色绑定或新动作库。
