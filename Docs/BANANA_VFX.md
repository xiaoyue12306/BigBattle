# 香蕉刺客：金月双刃特效

v0.4.0，2026-10-17。适用当前团结 1.9.3 / Built-in / Windows 版本。

## 视觉设计

主色为薄荷青、金黄和暖白，第二段加入浅蓝。月牙刃光用饱满的弧面、高亮刀芯、暗青色边缘和渐隐尾部组成；小型星芒与叶片延续香蕉角色的可爱风格。刀光围绕角色与攻击方向展开，不添加遮住整个画面的闪白或后处理。

| 攻击事件 | 新效果 |
| --- | --- |
| 普攻第一段 | 薄荷青横向月牙、暖金反向辅刃、沿刃缘飞出的星屑。 |
| 普攻第二段 | 蓝色反手月牙、相反的旋转方向和金色辅刃。 |
| 普攻第三段 | 更宽的金色主刃、倾斜交叉月牙、尖锐接触星芒、向前散开的叶片及地面金环。 |
| 突刺 | 从出刀位置延伸至接触位置的青白流光、沿路径分布的叶片、前端小型金环和亮点。 |
| 旋转连斩 | 跟随角色的反向旋转青金刃环、六枚环绕叶片，以及每段攻击的短弧脉冲。 |
| 香蕉皮落地 | 六枚青金叶片和短促地面圈，落地只触发一次。 |
| 拼刀 | 金白星爆、向外散开的叶片火花和快速扩散的碰撞环。 |

手部刀刃拖尾适度加宽、延长，配合已经接入的 Mixamo 动作。陪练的主要普攻刀光保留珊瑚红以区分敌对方向。

## 实现与后续调整

- `Runtime/Visuals/Art.cs` 缓存月牙、流光、星形 / 叶片网格及材质。月牙端点在分数次幂前钳制到非负，避免单精度 `sin(PI)` 的微小负值造成 NaN 网格。
- `Shaders/BladeEnergy.shader` 以 UV 控制刀芯、边缘羽化、细条纹和展开进度；无外部贴图、VFX Graph、商店资源或渲染管线依赖。构建配置显式保留此 Shader。
- `Feedback` 在统一近战接触时生成斩击 / 突刺效果，保留既有命中和拼刀事件；`BladeVortex` 管理一次连斩的三条弧带、六枚叶片和跟随时钟。
- 临时效果根节点上限为 220；重复攻击复用共享网格 / 材质，短寿命效果逐步透明并销毁。旋转光环用固定数量的子网格，动作结束、角色失效或重开时清理。
- 暂停使特效生命周期停止。光环 LateUpdate 在 timeScale 为零时不再更新，避免打开菜单的末帧继续转动。
- 美术尺寸与表现强度不参与伤害判定。普攻 24 / 27 / 36、突刺 42、连斩间隔 / 范围、75ms 拼刀规则和音效均沿用现有逻辑。
