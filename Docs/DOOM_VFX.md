# 万魂魔剑 · 灭世竖斩

v0.9.0，2026-10-17。团结 1.9.3 / Windows x64 / Built-in。

v0.10.0 保留本页竖刃 / 地裂，再以真实 Timeline 加入四秒聚能阶段、魂风 / 魂晶与错时释放冲击；轨道、共享资源和编辑方式见 [TIMELINE_VFX.md](TIMELINE_VFX.md)。下文保留 v0.9.0 竖斩基础记录。

## 表现

- 剑气由横向月牙改为 **8.8 单位高的立体竖向弯刃**，脚部贴近地面，世界上方向始终朝上。黑色主刃、青绿刃缘、蓝色魂脉、少量红色游丝和四条分叉电弧包围实体；前后、侧向和斜向释放都不会转成横向平面。外围使用已有许可的帧动画闪电、鬼焰及暗雾，主体不随相机转动。
- 地面由重复的细横折线改成沿飞行方向连续撕开的宽裂隙。焦黑地表托住蓝绿发光的裂缝与侧向分叉，沿途间歇出现翻起的碎岩和 64 帧蓝绿魂焰；四套裂纹变体打散高频锯齿节奏。每隔 1.2 单位落一段长 1.5 单位的重叠裂痕，低帧率长步进也按距离补齐。仅在当前地图可行走地面范围内生成，不在地图外水面上悬空铺线。
- 蓄力加入更大的暗色聚能场、六束反向盘旋的红蓝绿魂流、十八条收束流光、剑尖闪电与更多鬼焰。释放产生大范围双层流焰法阵、竖直闪光和扩散冲击；镜头在原有强震与冲击基础上短暂拉远，1.4 秒内收回。

## 规则与维护

- **只更改呈现**。三魂消耗、四秒蓄力、90% 移速降低、硬控 / 死亡 / 提前松开取消、20 秒释放冷却、速度 24 / 三秒寿命、固定方向贯穿和每目标一次 500 伤害均沿用原规则。视觉高度 / 鬼焰 / 地裂不扩大 2.1 单位的剑气扫掠半径、不产生额外伤害或碰撞墙。
- `GhostProjectile` 保留运动和命中；`DoomWaveVisual` 负责世界向上的立体刃与电弧，独立 `DoomRift` 保留沿途裂痕。投射物消失后地裂继续按自己的寿命回收；角色死亡不会留下永久地面物。
- `Art.DoomSurface` 缓存一套竖刃、四套分叉及四套焦痕网格；材质使用三个共享实例。每帧用 MaterialPropertyBlock 设置 `_Clock / _Opacity`，不在每次攻击创建永久材质或网格。`BigBattle/DoomEnergy` 在 ProjectBuilder 中显式保留；普通香蕉 BladeEnergy 未改。
- 每波最多 62 个候选采样点；全局最多 **192 段存活裂痕**，反馈根节点仍有 220 上限，弹体仍有 48 上限。裂痕 2.6 秒后渐隐，到 4.6 秒逐段销毁，碎岩沉回地面；最后采样后 4.7 秒清理根节点。数量上限不是未来多视口性能承诺。
- 网格 / 电弧 / 裂痕 / Shader 使用暂停后的游戏时钟；原生粒子继续经 GameRoot → SoulVfx.SetPaused 显式暂停。重开清空反馈根节点、地裂计数和临时镜头拉远。声音、静音与手柄请求仍走原入口。
- 复用已接入的 Kenney、Kutejnikov、Cethiel、para CC0 素材与本项目新网格 / Shader；本轮未下载新的商店包。原许可和源图哈希保持，见 SOUL_VFX.md 与 AssetLibrary/VFX 下的来源记录。

## 限制与下一步

地裂是贴地特效和装饰碎岩，不是地形几何破坏、真实光源或可穿越的深沟。场地仍使用原平面边界。大型发光增加绘制成本，真实 Xbox、电视、多视口和低配置机器仍需人工验收；后续先在目标电视查看亮度、巨刃比例与画面遮挡，再调整强度。

数值 / 暂停 / 清理 / 模式回归的最终结果见 [VALIDATION.md](VALIDATION.md)。
