# 阿狸 · 十字爆泡连锁（v0.12.0）

阿狸是第三位可战斗角色，女巫仍保留独立的技能待设计预览。选择第四张角色卡后可进入木桩练习、三波挑战、英雄陪练和花溪大乱斗。当前仍只有一个真人输入，未来最多五人本地多人未实现。

## 本轮确认的规则

- **J / Xbox X** 在角色所在位置放下泡泡；可按住连续放置，每次间隔 **0.22 秒**。只设计这一个技能，K / L / 空格 / I 对应的其他动作不释放香蕉技能，也没有额外伤害或闪避。
- 每位来源最多 **5 个尚未爆炸的泡泡**。数量不足五个且放置间隔结束即可放下新泡泡，不要求先把整批泡泡炸完。允许原地叠放；泡泡不阻挡行走。
- 放下后位置固定，呼吸缩放 / 轻浮动 / 高光持续 **1.8 个游戏秒**，随后爆炸。暂停冻结倒计时、呼吸及爆炸时钟。
- 爆炸以原位置为中心沿地图上 / 下 / 左 / 右发出十字直线波，**每臂 5 单位、宽 1.2 单位，0.15 秒内扩展至末端**，与人物朝向无关。花溪采用旋转后的地图纵横轴；四臂在当前可走边界停止，不绕弯延伸到水上。
- 每次泡泡爆炸对每个敌人最多 **80 伤害**，中心四臂交叉不叠加。自己和队友免伤，沿用目标无敌、建筑保护 / 无支援减伤及真实击败归属。不同泡泡各自造成伤害，连锁密集爆炸可叠加不同泡泡的伤害。
- 波触及其他尚未爆炸的泡泡（包括其他来源）立即引爆，对方泡泡保留自身伤害来源并继续产生四向波。采用碰撞半径，触到球面即可连锁；同一个泡泡只爆一次。波在 0.58 秒内回收，后段是无伤害余光。
- 爆炸发生时立即返还放置名额。场内已放下泡泡在来源暂时阵亡 / 花溪复活时保留，到时仍会爆炸；来源对象彻底移除、重开 / 切换角色 / 离开模式时清理。比赛结算后清空未完成泡泡和波，不再造成伤害。重开清空放置间隔，花溪复活保留当前间隔。
- 当前初始生命 180、移速 5 为首版适配数值；没有装备、经济、升级或联网系统。

上述按键、间隔、长度 / 宽度 / 传播时间、80 伤害和不伤友军规则已由用户本轮确认。效果参考用户本机 `C:\Users\xy\Pictures\bb\baozha.png` 的橙金 / 奶白十字爆炸，使用原创立体鼓泡网格和 Shader 重制，没有把参考图的背景或像素直接贴到场景。

## 模型与声音

原始用户模型 `C:\Users\xy\Pictures\bb\ali.fbx` 是 22,613,100 字节静态网格（24,987 顶点），没有骨骼或动画。保留红色外观、大头、铃铛和双尾，Blender 制作 19 根骨骼 / 区域蒙皮；移除 1,851 个展示底座顶点，剩 23,136 顶点，落地高度约 2.195 单位。原彩色图缩为 2048²。自制烘焙 **Idle / Walk / Place / Defeat** 四个 FBX 动作，实际距离驱动步态，放置触发短促手臂 / 躯干动作，双尾轻摆。

公开仓库保存游戏用衍生 `Resources/Ali/Ali.fbx`、`AliColor.png` 和 `.meta`；原文件、Blender 中间文件与原始帧留本地。来源及产物校验见 [ali-assets-v0120.json](Validation/ali-assets-v0120.json)，并不将用户素材标记成 CC0 或从商店领取的资产。

本机重新制作：`E:\blender\blender.exe --background --python Tools/PrepareAli.py`，保留已有 `.meta`。普通 Windows 构建直接使用生成的模型，不需要再次运行 Blender。`AliModelImporter` 固定 Legacy 导入 / 无压缩，构建要求实际存在四个片段。

新增原创放泡泡 / 爆泡两种声效，各四个变体，音效库总计 68 个。清脆滑音、低频爆破与短水汽尾音经过原音量余量 / 池 / 间隔 / 静音路径，不绕过全局静音。

## 实现与交接

- `AliPlayer`：独立移动 / 朝向、0.22 秒放置门槛、唯一攻击入口、重开 / 复活状态，不继承香蕉战斗。
- `BubbleField`：每场惰性创建的中央泡泡 / 波管理器，按来源记录名额。爆炸先移除待爆记录，再生成波；迭代处理连锁，不递归、不重复消耗。按扩展到达的整个十字区域扫掠，长帧也检查全部经过路径；命中集合确保同波一次伤害。
- 全局 **96 个待爆泡泡 + 活跃波的合计预约**，爆炸转换时保留预算；泡泡每位五个。此数量保护不是多人 / 低配性能验收。
- `BubbleVisual` / `BigBattle/BubbleEnergy`：共享五团鼓泡网格、共享材质、MPB 传入缩放游戏时钟与局部衰减。待爆半透明金色球、高光 / 涟漪和地环；爆炸按近远分段展开白芯金色云团 / 水滴，有限余光。无逐次命中永久材质、网格或场景灯。
- `AliVisual`：禁用自动播放的 Legacy Animation 手动 Sample，混合实际位移步态、待机、放置和倒下；暂停冻结、重开清零，不移动战斗根节点。
- 花溪只在阿狸主控时明确加入每队一位阿狸 AI，仍一真人 + 九 AI；原两英雄主控的阵容保持。AI 沿地图轴对齐目标再放泡泡，沿用原推进 / 支援 / 撤退。陪练菜单可循环三种战斗英雄，阿狸陪练是无魂印奖励的可恢复训练对象。
- 越越大王可真实击败 / 召回阿狸：亡魂 90 生命、40 爆泡伤害，自主移动 / 放泡泡，保留原半属性和 20 秒寿命规则。

## 验证与边界

运行 `Tools/Build.ps1`、`Tools/CheckSource.ps1`、`Tools/Smoke.ps1` 和 `Tools/LaneSimulation.ps1`；模拟增加阿狸主控第三场。`AliChecks` 覆盖模型 / 动作 / Shader、移动放置间隔、位置与呼吸、暂停、五枚名额、独立来源、完整 fuse、返还、200ms 长帧四臂伤害、中心一次、斜角 / 超距免伤、无敌 / 友军、连锁、静音、共享材质、合计预算、模式 / 旋转轴 / 边界 / 复活、半属性召回及无奖励陪练。女巫预览和原英雄整套回归仍要通过。

真实帧录制：`Tools/PreviewAli.ps1`，再运行 `Tools/MakeAliGif.py`。诊断近景可展示泡泡与四向波，不能当作实时 FPS 或手动对局证明。新模型区域蒙皮仍为基础版本，无精细脚 IK、布料、手指 / 面部动画；金色爆炸在多泡同时引爆时会遮挡局部目标，目标电视亮度 / 性能、实体手柄 / 重连 / 震动及多人分屏待单独实测。
